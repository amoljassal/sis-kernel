# SIS Kernel Reference Documentation

This directory contains all historical documentation, consultations, and development artifacts organized for easy navigation by development teams and AI agents.

## 📁 Directory Structure

### `/documentation/`
Main development documentation organized by purpose:

- **`architecture/`** - Core system design, brainstorming sessions, cognitive architecture
- **`blueprints/`** - High-level project blueprints and strategic documents  
- **`implementation-phases/`** - Phase-by-phase implementation documentation (PHASE_1, PHASE_2, etc.)
- **`multi-ai-consultations/`** - Multi-AI collaboration sessions and consultations
- **`progress-reports/`** - Achievement reports, debugging logs, CI fixes

### `/Current-arm64-development/`
Active ARM64 development materials:

- **`AI-Lab/`** - AI-Lab specific development logs
- **`Blueprints/`** - Current development blueprints
- **`development-protocols/`** - Development methodologies and protocols
- **`logs/`** - Development session logs

### `/legacy-Initial-development-phase/`
Historical development materials:

- **`chatgpt-memory/`** - ChatGPT collaboration logs and patches
- **`grok-memory/`** - Grok AI collaboration materials
- **`original-idea/`** - Initial project conception documents

### `/sis-unified-rag/`
RAG integration and knowledge management:

- Implementation blueprints for RAG systems
- Modular OS extractions
- Feature documentation

## 📋 File Naming Convention

- `PHASE_X_*.md` - Phase-specific implementation docs
- `MULTI_AI_*.md` - Multi-AI consultation sessions
- `SIS_*.md` - Core system blueprints/protocols
- `*_CONSULTATION.md` - Consultation session transcripts
- `*_SYNTHESIS.md` - Synthesized outcomes from consultations
